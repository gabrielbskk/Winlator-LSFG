# Security policy

Winlator LSFG is an experimental, unofficial fork. Compatibility and security fixes may depend on upstream Wine, Box64, Mesa, Android dependencies and distributed runtime components.

## Reporting security issues

Please avoid disclosing sensitive vulnerability details, credentials, private device data or full exploit instructions in public issues or pull requests. Contact the repository maintainer through a private contact channel listed on their [GitHub profile](https://github.com/gabrielbskk), if one is available, or use GitHub private vulnerability reporting if the feature has been enabled for this repository. If neither channel is available, do not post confidential exploit details publicly.

Include affected revision, environment, expected vs actual behavior and a minimal non-sensitive reproduction summary.

## Supported versions

No fixed security-support or patch schedule has been announced. New releases should state any relevant security constraints explicitly.
