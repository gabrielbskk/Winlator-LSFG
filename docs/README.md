## Referências históricas

[RPC Android](DISCORD_RPC.md), [capas de jogos](RPC_GAME_ARTWORK.md) e os documentos Experimental 4/5/6 registram integrações anteriores. O fluxo com Application ID descrito nesses guias não é o fluxo ativo da RC8. Para o APK atual, use o guia de clientes Windows acima.

A [tag RC8](https://github.com/gabrielbskk/Winlator-LSFG/tree/aurora-11.3-rc8-discord-firefox) identifica o código do APK publicado. A documentação da página principal pode ser atualizada antes da integração de todas as mudanças de aplicativo na `main`.
